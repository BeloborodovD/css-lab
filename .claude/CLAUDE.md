# CLAUDE.md — css-lab

Лаборатория интерфейсного ремесла: витрина компонентов и тем (`index-v3.html`,
`styles/`), на которой отрабатываются дизайн-система, движение и доступность прежде,
чем попасть в продуктовые проекты.

Проект самодостаточен: агенты, скиллы и хук лежат внутри `.claude/` и не зависят от
глобальной `~/.claude/`. Каталог переносится на другую машину как есть.

## Запуск

```bash
npm run dev          # live-server на :5173
make up              # dev-контейнер на :48621
make prod            # прод-сборка на :48620
make health          # проверка контейнеров
```

## Свод правил движения — обязателен

`.claude/skills/ui-motion-craft/RULES.md` — спецификация для любого кода, который
пишет CSS, компоненты или анимации. Значения оттуда копируются буквально, а не
подбираются по памяти. `.claude/skills/ui-motion-craft/tokens/motion.css` — слой
токенов, подключается первым в каскаде; хардкод `cubic-bezier`/`ms` в компонентах
после этого считается дефектом.

Соблюдение подкреплено хуком `.claude/hooks/motion-lint.py` (PostToolUse на
Write/Edit): он блокирует `ease-in`, `transition: all`, `scale(0)`, анимацию
layout-свойств и reduced-motion-рубильник, возвращая готовую замену.

## Локальные агенты

| Агент | Зона |
| --- | --- |
| `dev-ux` | user flow, вайрфреймы, спецификация интеракций |
| `dev-brand-identity` | палитра, типографика, тени, дизайн-токены |
| `dev-css` | реализация стилей, темы, адаптивность |
| `dev-web-animation` | движение по спецификации |
| `dev-frontend` | разметка, состояние, интеграция |
| `dev-accessibility` | WCAG 2.2, фокус, клавиатура, контраст |
| `dev-landing-page` | архитектура секций и конверсия |

Порядок конвейера: `dev-ux` → `dev-brand-identity` → `dev-css` → `dev-web-animation`
→ `dev-frontend` → `dev-accessibility`.

| Скилл | Когда |

| `ui-motion-craft` | Свод правил и токены движения. Читается первым |

| `find-animation-opportunities` | Где движения не хватает и где оно вредит |
| `animation-vocabulary` | Точное название эффекта |
| `pick-ui-library` | Выбор библиотеки вместо самописного тоста или диалога |
| `prototype` | Несколько вариантов одного UI с переключателем |
| `frontend-design` | Общая планка визуального качества |
| `responsive-design` | Брейкпоинты и адаптивные сетки |
| `wcag-accessibility` | Критерии доступности |

Скиллы вызывает главный агент: у `dev-*` в `tools:` нет инструмента `Skill`, они
читают свод правил через `Read` по пути из своего промпта.

## Конвенции

- Комментарии в коде — русские, идентификаторы и классы — английские.
- Ответы пользователю — русские.
- Токены прежде компонентов: ни одного литерала цвета, отступа, кривой или
  длительности в стилях компонента.
- Файлы пишутся инструментами Write/Edit. PowerShell `Set-Content`/`Out-File`
  добавляет UTF-8 BOM, из-за которого определения агентов и скиллов молча выпадают
  из реестра.
