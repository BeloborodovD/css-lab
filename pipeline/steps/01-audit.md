# Шаг 01 — Аудит целевого проекта

**Агент:** `dev-ux`. Для лендингов/маркетинговых страниц дополнительно (параллельно,
отдельный отчёт): `dev-landing-page`.

**Вход:** путь до целевого проекта.
**Выход:** `<target>/.claude/redesign/audit.yaml`.

## Задача

Пройти все страницы/экраны целевого проекта и составить инвентарь:

1. **Каталог элементов** — каждый UI-элемент: название, где живёт (файл:строка,
   страница), текущая реализация (свои стили / фреймворк / инлайн).
2. **Проблемы эргономики** — по скиллам `css-lab/.claude/skills/`
   (apple-design, find-animation-opportunities, wcag-accessibility, читать через
   Read): цели < 24px, отсутствие фокус-состояний, недоступные с клавиатуры
   контролы, отсутствие/избыток движения, несогласованные отступы и шкалы.
3. **Карта пользовательских потоков** — ключевые сценарии и где они спотыкаются.

## Формат audit.yaml

```yaml
project: <имя>
pages:
  - path: <файл/маршрут>
    elements:
      - name: <элемент>        # кнопка, дропдаун, таблица…
        source: <файл:строки>
        impl: custom|framework|inline
        issues: [<эргономика/a11y/motion>]
flows:
  - name: <сценарий>
    friction: [<где спотыкается>]
```

## Гейт

audit.yaml полон (каждая страница разобрана), у каждого элемента есть source.
Оркестратор передаёт файл на шаг 02.
