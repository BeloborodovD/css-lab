# Шаг 06 — Доступность

**Агент:** `dev-accessibility`.

**Вход:** целевой проект после шагов 04–05, `audit.yaml` (находки a11y),
скилл `wcag-accessibility` (читать через Read).
**Выход:** целевой проект на уровне WCAG 2.2 AA.

## Задача

1. Клавиатура: все интерактивы достижимы Tab-ом, панели закрываются Escape,
   фокус возвращается на триггер, ловушек фокуса нет (кроме модалок с inert).
2. Фокус-кольцо: двухслойный `--shadow-focus` из токенов, `:focus-visible`.
3. Семантика: роли/aria-атрибуты по образцам компонентов css-lab (disclosure для
   меню, aria-pressed на тумблерах, aria-live для статусов, sr-only подписи).
4. Контраст: текст ≥ 4.5:1, крупный/UI ≥ 3:1 — проверить фактические пары
   темы бренда в обоих режимах (light/dark).
5. Цели касания ≥ 24×24px.

## Гейт

Отчёт: находка → файл:строка → исправление. Блокеры (недоступный с клавиатуры
контрол, контраст < 3:1) должны быть исправлены, не задокументированы.
